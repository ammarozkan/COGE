# COGE
Critical Oriented Game Engine
## Targets
- [x] One loading screen at start and nothing else. Every other loading segment shall be in game. invisibly.
- [x] Can use all datas(model,shader etc.) in a packed data file.
- [x] Have a DebugUI without any letter files. Only vertices and indices summed together.
- [x] Controller system with camera management.
- [x] Terrain generator.
- [x] Really basic water. Really basic. Don't expect too much.
- [x] Thirdperson Controller
- [x] Flight Controller
